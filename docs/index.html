This is the query tool for the SPARQL part of the practical. It holds the same pizza ontology you explored in WebProtégé, stored as RDF triples. Here you query those triples with SPARQL, the standard query language for knowledge graphs.

Everything runs in your own browser with the Comunica query engine (IDLab, Ghent University – imec), with thanks to its developers. No installation is needed. Follow the questions in the Canvas quiz.

About this practical

This tool belongs to the Reasoning with Health Data practical of MAM04, Data Driven Decision Making and Evaluation in Medicine, in the Master Medical Informatics (University of Amsterdam / Amsterdam UMC).

The data is the pizza ontology from the Protégé part of the practical. It has classes (e.g. pizza:Margherita), properties (e.g. pizza:hasTopping) and individuals (the countries). The class hierarchy that a reasoner infers is already included, which is why pizza:Rosa shows up as a pizza:CheeseyPizza.

Pick a saved query on the left, press Run (or Ctrl/⌘ + Enter), and click any blue link to see everything that is known about that class or property. Lines that start with # are comments and are not run. Answer the questions in the Canvas quiz.
